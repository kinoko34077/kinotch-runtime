# KiNoTch. Runtime v0.1 Implementation Plan

> For agentic workers: use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Create a minimal, dependency-free Python Runtime reference implementation that can be evaluated first by `jev-audit`.

**Architecture:** Keep execution contracts as small immutable/value-oriented Python objects. `ActionRegistry` owns registration and invocation; `ActionContext` carries explicit configuration, logging, progress, and cancellation dependencies. The Runtime returns structured results for expected and unexpected failures without adding Surface adapters.

**Tech Stack:** Python 3.10+ standard library, unittest, JSON-compatible dataclasses, and KiNoTch. Repository Base v0.2.1 common tooling.

**Spec:** `project/docs/SPEC.md`

## Global Constraints

- No third-party Runtime dependency.
- No CLI, MCP, API, Agent, Windows GUI, filesystem abstraction, deployment, auth, retry, or provider policy.
- Config reads are explicit; secrets are not logged.
- Cancellation is cooperative.
- `jev-audit` is not modified in this phase.
- Every task ends with tests and a commit/push boundary.

## Task 1: Contract value objects

Files: `project/src/kinotch_runtime/errors.py`, `result.py`, `progress.py`, `resources.py`, `config.py`, `logging.py`, and tests.

- Write tests for JSON-compatible serialization, extensible error codes, result statuses, progress callbacks, resource/artifact values, explicit config reads, and logger creation.
- Confirm RED before implementation.
- Implement only the dataclasses and small helpers required by those tests.
- Run the full unittest suite and commit.

## Task 2: Execution kernel

Files: `project/src/kinotch_runtime/kernel.py`, `__init__.py`, and tests.

- Write tests for registration/execution, unknown action, ActionErrorException, unexpected exception redaction, and cooperative cancellation.
- Confirm RED before implementation.
- Implement `ActionRequest`, `ActionContext`, `CancellationToken`, `ActionRegistry`, and the health example.
- Run unit tests plus `knt doctor` and `knt verify`, then commit.

## Task 3: Repository closeout

- Add package/readme documentation and current state.
- Validate project/action/surface schemas through Base doctor.
- Run the Base self-test, Runtime unittest suite, doctor, verify, smoke semantics, whitespace check, and CI.
- Confirm local `main` equals remote `main` and publish the repository.
